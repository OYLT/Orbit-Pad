# 陀螺仪启动校准与 F1 转向预设

日期：2026-10-31。

撤回上次基于 X/Z 重力向量的转向实现，恢复旋转向量传感器：优先 TYPE_GAME_ROTATION_VECTOR，缺失时使用 TYPE_ROTATION_VECTOR。转向角以校准后的握持姿态为中心，按手机屏幕法线计算，不要求屏幕朝上放平。回中按钮及其旧布局配置一并恢复。

每次进入手柄、开启陀螺仪或从后台、设置、暂停及断线恢复控制时重新校准。校准要求姿态在 1.5° 内稳定至少 600 ms，移动时重新计时；完成前输出零转向，状态栏提示保持手机稳定。手动点击「回中」执行相同校准。关闭陀螺仪时不启动传感器或显示校准提示。

转向比仅提供 F1 标准和自定义，已删除家用车标准。F1 总行程为 360°，左右各 180° 满舵，采用 [Logitech 官方文档中的常见 F1 模拟方向盘行程](https://support.logi.com/hc/en-nz/articles/8358055253271-In-Game-Settings-for-Pro-Wheels)，并非所有赛车必须遵守的统一参数。自定义单侧角度范围为 15°–450°，旧自定义角度保持不变。传感器累计跨圈转角，避免经过 ±180° 时突然反向；提交核心的角度限制在 ±450°，超过满舵角后保持满舵，反向回转时正确恢复。

自动验证：

- Java：332 项检查通过，涵盖校准等待、移动重计时、任意握持姿态、手动/重新开始校准、四元数等价符号、横屏两个方向、跨圈累积及反向回到中心、无效传感器数值。
- Rust：14 项单元测试、fmt、Clippy 通过，新增 F1/自定义范围、左右满舵、半舵、归零、越界拒绝及回中布局保留检查。
- Rust 与接收端协议：80 项检查通过。
- Android：ARM64 与 x86_64 构建完成，APK v2/v3 签名及 16 KB 对齐校验通过，延续项目原签名。

Redmi K40 Pro+（Android 16）真机 10 个接收端核对阶段全部通过。验证已启用陀螺仪时重新进入手柄会自动开始校准、校准期间零转向、稳定后完成，以及手动回中、设置/断线释放；预设选择器仅含 F1 与自定义，F1 角度可写入核心并持久保存。测试结束后恢复用户原设置。

真机记录保存至 `artifacts/gyro-calibration-f1`，其报告包含本轮安装 APK 的 SHA-256。测试使用 USB / ADB reverse 通道和预览接收端；不代表已在具体赛车游戏中验证驾驶手感或实体手机转动方向。
