# 原生赛车功能与网页端移除验证

日期：2026-10-22。

本文记录历史重力转向实现。2026-10-31 已撤回该实现，恢复相对姿态转向，新增启动自动校准并保留 F1 与自定义转向比，见 [当前验证记录](GYRO-CALIBRATION-VALIDATION.md)。

## 自动验证

- Node：18 项通过，包含真实 Windows XInput 模拟量读回、看门狗归零、旧 22 控件映射升级、网页路由返回 404、原生配对和二维码继续可用。
- Xbox：Windows 键盘钩子捕获并抑制测试快捷键，确认每次按下输出完整按下/松开序列，保持按住与心跳不会重复触发；测试不会打开电脑 Game Bar。
- Java 重力计算：39 项检查通过，覆盖 X/Z 正负角度、不同重力投影幅度、放平回中、固定重力基准、投影退化与无效数值。
- Rust：13 项单元测试、fmt 和 Clippy 通过，覆盖横/竖线性扳机、数字开关、独立释放、旧模板迁移及回正控件清理、陀螺仪转向、触摸优先、后台归零与参数校验。
- Rust 与真实接收协议：80 项检查通过，包含 Xbox、全部游戏控件、多指、配对、暂停、断线、超时、重连、USB 和蓝牙的本地协议握手。
- Windows 新包及解压后自检通过，确认原生桥接就绪、二维码、暂停、恢复与退出；压缩包断言不包含 app/public 网页资源。
- Android ARM64 / x86_64 构建完成，APK v2 / v3 签名校验通过。

## 真机

Redmi K40 Pro+，Android 16。通过 USB ADB reverse 测试通道连接预览接收端，未使用生产 USB 自动配对流程。

验证 A 键尺寸滑块实时改变控件边界；LB 宽高独立保存；Xbox 控件显示；竖向 LT 输出约 25%；同时横向 RT 输出约 75%；抬起 LT 后 RT 保持原值；触摸取消全部归零；设置可正常显示。

确认设备重力传感器可用，控制时注册监听、进入设置及断开后停止监听，设置及断开时输出中立；已知 X/Z 重力向量得到正确的 ±23.5° 转向角，控件列表不再包含回正按键。8 个接收端核对阶段全部通过，记录与截图位于 artifacts/gravity-xz；该记录的 APK SHA-256 与本次构建一致。

本次转向改用 TYPE_GRAVITY，只读取设备 X/Z 分量，屏幕朝上放平为固定中心，不再记录启动姿态或提供手动校准。Android 系统仍返回三分量事件，应用不读取或保存 Y 分量。真机测试沿用已保存布局，尺寸预览检查先设置已知尺寸，再比较变化，最终恢复用户设置。
