# 手动陀螺仪校准

日期：2026-11-01。本地 Android 更新，沿用 0.5.0 版本与原签名。

手柄和编辑器不再显示回正按键。旧模板中的 `calibrate` 布局字段仍能加载，其他布局与手感设置保留，该控件不再进入渲染布局。

开启陀螺仪后进入手柄，显示居中的圆角悬浮二级菜单，不缩放手柄画布，也不启动传感器。点击「开始校准」后才采样，握持姿态在 1.5° 内稳定至少 600 ms 后记录中心，移动会重新计时。完成后菜单关闭。等待、采集中和取消后转向均为零；完成后才输出陀螺仪转向。

「暂不校准」、「取消校准」或返回键关闭菜单并停止采样，不会再次自动开始。可从「设置 → 手感调节 → 陀螺仪校准」重新打开菜单。重新进入手柄、后台或设置返回、断线恢复时重新提示，仍须点击开始。关闭陀螺仪或无传感器时不显示提示。校准期间暂停游戏震动，避免影响稳定检测。

验证结果：

- Java 陀螺仪检查 342 项通过，包括未点击不校准、停止后解除采样资格、无效数据不自动重启，以及原有姿态与跨圈检查。
- Rust 18 项单元测试、fmt、Clippy 通过；原生接收端协议检查 82 项通过。
- Redmi K40 Pro+ / Android 16 真机 15 个接收端核对阶段通过，包括等待开始、校准完成、重入等待、取消保持零转向、设置中手动发起、后台停止及恢复等待。测试还核对线性扳机与断线释放。
- 真机报告与截图：`artifacts/manual-gyro-calibration-final`。使用 USB / ADB reverse 与预览接收端；未验证具体赛车游戏驾驶手感或实际 XInput 输出。
- 双架构 APK 已构建，并通过原签名、v2/v3 签名和 16 KB 对齐检查。文件为 `releases/OrbitPad-Android-v0.5.0.apk`，SHA-256 见 `releases/SHA256SUMS.txt`。

本次校准流程只需更新 Android；电脑接收端无需因本项变更更新。APK 随 [v0.5.0-themes-rumble](https://github.com/OYLT/Orbit-Pad/releases/tag/v0.5.0-themes-rumble) 发布；同版游戏震动功能需要同时更新 Windows 接收端。
