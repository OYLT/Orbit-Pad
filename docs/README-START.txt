【原生手柄版 / XInput】
本地版本输出 Xbox 360 原生虚拟手柄，已取代电脑键盘映射。
首次使用：完整解压后运行“安装手柄驱动.cmd”，按向导安装 ViGEmBus，
然后重新启动 OrbitPadReceiver.exe。已安装 ViGEmBus 的电脑可直接使用。
LT / RT 默认按住全按；手感设置可开启线性油门 / 刹车。
开启后沿长边滑动：左/上端 0%，右/下端 100%，松手归零。
Xbox 键使用本 App 图标，通过 Win+G 呼出已安装并启用的 Game Bar。
陀螺仪赛车转向可在手感设置开启，每次进入手柄或恢复控制时自动校准。
握好手机并保持稳定约 0.6 秒，以当前姿态为中心；游戏内可点「回中」重新校准。
转向比提供 F1 标准（总行程 360°，左右各 180°）和自定义角度，支持死区与反向。
网页端已删除，只保留 Android App 与 Windows 接收端。

ORBIT PAD 0.5.0 — 手机手柄、模板自定义与多种连接方式

【电脑端：Windows 10 / 11，64 位】
1. 完整解压 OrbitPad-Receiver-Windows-x64-v0.5.0-native.zip。
2. 打开解压后的文件夹，双击 OrbitPadReceiver.exe。
3. 窗口出现“接收端已就绪”后，记下电脑局域网地址和六位配对码。
4. 保持接收端运行，把电脑前台切换到要操作的游戏。

无需单独安装 Node.js。EXE 与 app、runtime 文件夹必须放在一起。
依赖 Windows 自带的 .NET Framework 和 ViGEmBus 手柄驱动。
如默认端口被占用，程序会在 3210–3230 范围内自动选择空闲端口。
最小化进入系统托盘；关闭窗口会停止服务、断开手机并释放所有按键。
“暂停输入”可临时停止手柄输出；“重置配对”会撤销所有手机的配对凭据。

【手机端：Android 8.0 或以上，ARM64 / x86_64】
1. 将 OrbitPad-Android-v0.5.0.apk 传到自己的 Android 手机并安装。
2. 手机与电脑连接同一个 Wi-Fi。
3. 在手机 Dock“连接”页默认选择扫码，打开相机扫描电脑上的二维码。
4. 识别后自动配对、横屏并进入手柄；也可选“手动配对”输入地址和六位码。
5. 使用系统返回手势可断开连接、更换电脑。

APK 包含原生连接页、手柄和设置界面，由 Rust 核心直接与电脑接收端通信。
连接后不需要互联网，需保持所选的局域网、USB 或蓝牙通道。
相机权限仅用于主动打开扫码页面；支持从图片识别二维码。
不依赖 Android System WebView。沿用同一签名，可覆盖安装 0.3.0 / 0.4.0。
本地设置保存在 App 内；旧版 WebView 内保存的映射需要在新版重新设置。

【主页与 Dock】
底部悬浮 Dock 提供主页、连接、主题和关于四页。
主页可切换预设，编辑按键布局、映射和手感，保存、加载和删除自定义模板。
布局编辑页与使用界面保持完全相同的画布比例和尺寸。
点击控件打开悬浮圆角菜单，在位置、尺寸、显示之间切换。
方向键与 XABY 默认分别绑定为组，拖动和缩放作用于整组，可解绑后单独编辑。
XABY 与 LB/LT/RT/RB 共用连续宽高调节，尺寸自动约束在屏幕内。
「保存并返回」更新当前配置的独立样式；「显示控件」可恢复隐藏控件。
主页横向卡片显示每个配置已保存的实际布局，左右滑动或点击箭头切换。
切换包含高斯模糊与堆叠动画，系统关闭动画时直接切换。
主题页暂时空白；关于页列出版本和应用信息。
手柄全屏时可在设置对话框点击“返回主页”，保留连接进入 Dock 页面。

【USB 数据线直连】
1. 用数据线连接手机和电脑，在手机开发者选项开启 USB 调试并确认本机授权。
2. 电脑接收端点击“USB 连接”，多台手机时选择对应设备。
3. 手机连接页选择“USB 直连”，点击“连接 USB 手柄”，自动完成配对。
不需要 Wi-Fi 或 USB 网络共享。只配置本次手机的 tcp:3210 到当前接收端端口映射。
正常关闭电脑接收端会移除由本次进程建立的 USB 映射。

【蓝牙直连】
1. 手机与电脑均开启蓝牙，在两端系统设置完成配对。
2. 电脑接收端点击“蓝牙连接”开启服务。
3. 手机连接页选择“蓝牙直连”，授权附近设备权限，再选择已配对的电脑。
使用加密 RFCOMM，不需要 Wi-Fi 或蓝牙网络共享；电脑蓝牙适配器须支持经典蓝牙。
只配对并不代表连接到手柄服务，电脑接收端仍须保持运行。

【默认手柄控件】
双摇杆输出独立模拟轴，方向键输出原生十字键。
ABXY、LB/RB、LT/RT 均输出对应 Xbox 手柄控件。
View=Back，Menu=Start。全屏右上角的设置按钮可修改按键映射和死区。
设置页按系统返回键会关闭设置；在手柄页返回会询问是否断开。
全部应用界面采用 Material Design 3 深色风格。

【连接问题】
多网卡电脑请选择与手机同网段的 WLAN / Wi-Fi 地址。
若系统询问网络权限，请根据自己的网络环境允许接收端在专用网络中通信。
无法连接时检查防火墙、访客 Wi-Fi、AP 隔离和 VPN 路由。
若系统提示驱动缺失，请完成 ViGEmBus 安装并重启接收端。

当前通过 ViGEmBus 输出 Xbox 360 / XInput 虚拟手柄和模拟量。
游戏须支持手柄操作。尚未验证具体游戏兼容性。
局域网方式使用未加密 HTTP / WebSocket，仅在可信局域网使用，不要转发到公网。
