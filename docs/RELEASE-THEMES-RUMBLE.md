# Orbit Pad 0.5.0 · 主题、手动校准与游戏震动

发布标签：`v0.5.0-themes-rumble`。发布日期：2026-11-01。

应用内版本保持 0.5.0，沿用原包名与发布签名，可覆盖安装并保留模板、映射和手感设置。

## 更新

- 新增液态玻璃与 Material 3 主题页，全局跟随系统 / 浅色 / 深色模式、六组 HCT 配色，以及 Android 12+ 壁纸动态取色。
- 液态玻璃折射强度支持 0–160% 连续调节和真实渲染预览；Material 3 使用固定底部 / 侧边导航。
- 横屏页面独立滚动，导航移至左侧，旋转保留页面与表单；手柄和编辑器使用完整画布，工具栏与设置入口位于顶部中央。
- 陀螺仪进入或恢复控制时显示校准菜单，点击「开始校准」后才采样；稳定约 0.6 秒记录中心。支持暂不校准、取消和从手感设置重新发起，移除回正按键。
- 新增「极限竞速：地平线」模板，默认开启线性扳机与游戏震动。Windows 接收真实 XInput 双马达输出并传至手机，游戏震动与按键触感独立设置。
- 后台、失焦、设置、断线、暂停及反馈超时均停止震动并释放输入；保留旧客户端兼容性。

## 下载与安装

Android 安装附件 `OrbitPad-Android-v0.5.0.apk`，支持 Android 8.0+、ARM64 / x86_64。Android 13+ 支持完整玻璃折射，旧系统使用降级效果。

Windows 完整解压 `OrbitPad-Receiver-Windows-x64-v0.5.0-native.zip`，支持 Windows 10 / 11 x64。首次运行「安装手柄驱动.cmd」，再启动 `OrbitPadReceiver.exe`。

**游戏震动需要同时更新 Android 和 Windows 接收端，并在游戏内开启手柄震动。** 手机按两马达的最大强度输出单马达震动。安装包校验值见附件 `SHA256SUMS.txt`。

## 发布验证

本次上传前已通过：20 项 Node 测试（含真实 Windows XInput 输入及马达反馈）、342 项 Java 陀螺仪检查、18 项 Rust 单元测试、fmt、Clippy、82 项 Rust / 接收端协议检查及布局几何检查。

两个 Android 架构重新构建，APK v2 / v3 签名、16 KB 对齐、安装包完整性和 Windows 压缩包解压后自检通过。签名记录、Rust 构建记录与 Windows 自检记录作为附件提供。

此前真机验证范围与限制分别记录在 [主题说明](THEMES.md)、[横屏说明](LANDSCAPE-UI.md)、[手动校准说明](MANUAL-GYRO-CALIBRATION.md) 和 [游戏震动说明](FORZA-FEEDBACK.md)。本次发布未重新操作手机；没有启动实际《极限竞速：地平线》验证驾驶及路面手感，也未在 Android 8–12 物理设备复测降级效果。
