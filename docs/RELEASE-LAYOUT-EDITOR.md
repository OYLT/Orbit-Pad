# Orbit Pad 0.5.0 · 分组布局编辑与自动校准

发布标签：`v0.5.0-layout-editor`。发布日期：2026-10-31。

本版发布最新 Android 布局与赛车转向更新，应用内版本保持 0.5.0，沿用原包名和发布签名，可覆盖安装。

## 更新

- 编辑与使用手柄共享完整画布，工具栏和位置、尺寸、显示菜单悬浮显示，避免编辑时压缩布局。
- 方向键与 XABY 默认分别成组，支持整体移动、缩放，也可解绑后单独修改。按键支持连续宽高调整，并约束在屏幕内。
- 主页改为横向配置卡片，各卡片独立预览保存的布局、尺寸与显隐，支持滑动、左右箭头切换，以及高斯模糊和堆叠动画。
- 保存并返回会更新当前配置，也可另存模板；旧配置自动补充默认分组，保留映射和手感设置。
- 赛车转向恢复旋转向量相对姿态计算，每次进入或恢复控制时，保持手机稳定约 0.6 秒完成校准；保留手动「回中」，校准期间转向为零。
- 转向比提供 F1 标准（总行程 360°、左右各 180°）和自定义（单侧 15°–450°），支持跨圈角度累积、死区、反向和触摸优先。
- 保留液态玻璃 Dock、减弱后的果冻动效、线性扳机、Xbox / Game Bar 控件和后台释放。网页端继续保持移除。

## 下载与安装

安装附件 `OrbitPad-Android-v0.5.0.apk`。最终 APK SHA-256 为 `de787236e2488bf7dd7a6e34355698c89f6a00d205a89517f99e2047a4c0b0ec`。

Windows 完整解压 `OrbitPad-Receiver-Windows-x64-v0.5.0-native.zip`，首次运行「安装手柄驱动.cmd」，再启动 `OrbitPadReceiver.exe`。协议兼容已有原生接收端；本次 Windows 包同步更新使用说明，程序代码保持原版。全部附件校验值见 `SHA256SUMS.txt`。

Android 支持 8.0+、ARM64 / x86_64，Windows 支持 10 / 11 x64。完整液态玻璃效果需要 Android 13+，较旧系统使用降级效果。
